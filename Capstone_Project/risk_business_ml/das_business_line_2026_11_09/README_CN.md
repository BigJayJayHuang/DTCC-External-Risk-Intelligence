# DAS 业务线：公开证据与传导链

数据采集日期：2026-11-09。文档内容由现有 AWS Bedrock API 阅读、理解和提取；本地负责采集、证据核对、格式整理和入库。

业务范围：DTC Digital Asset Solutions，重点是 DTC 托管证券的代币化、去代币化及其与传统系统的衔接。DDA 技术产品属于项目的另一条业务线。

本次结果是待审核的研究输入。尚未取得连续的 DAS 内部缓冲或运行结果，未进行事件—业务指标相关性检验，也未给出风险分数。

## 官方事实

- DTS于2026年10月28日正式上线，是一项自愿性服务，允许符合条件的DTC参与者对DTC托管证券进行代币化。 ([launch](https://www.dtcc.com/press-releases/2026/dtcc-tokenization-service-goes-live))
- 上线时有20家DTC参与者签署了DTS接入协议；未来用户将滚动式入驻。签署协议不等于活跃用户。 ([launch](https://www.dtcc.com/press-releases/2026/dtcc-tokenization-service-goes-live))
- SEC交易与市场部门工作人员于2025年12月11日就初步基础版本发布不采取行动立场，涵盖Reg SCI等条款。这是工作人员立场，非委员会全面批准。 ([sec_staff_web_excerpt](https://www.sec.gov/files/tm/no-action/dtc-nal-121125.pdf))
- 合格证券包括试点上线时的罗素1000成分股及其后新增证券（即使其后被移出指数）、美国国债及追踪主要指数的ETF。 ([sec_staff_web_excerpt](https://www.sec.gov/files/tm/no-action/dtc-nal-121125.pdf))
- DTC不会将任何代币化权益赋予抵押品价值或结算价值，不用于DTC风险管理（包括净借记上限或抵押品监控）计算。 ([sec_staff_web_excerpt](https://www.sec.gov/files/tm/no-action/dtc-nal-121125.pdf))
- LedgerScan和Factory被指定为二级系统，恢复时间目标为四小时，最大数据丢失两分钟，并须进行年度异地灾难恢复测试，且与DTC的SCI清算/结算系统物理和逻辑隔离。 ([sec_staff_web_excerpt](https://www.sec.gov/files/tm/no-action/dtc-nal-121125.pdf))
- 代币仅可转移至DTC参与者的已注册钱包。DTC保留技术能力，可在满足"需要撤销条件"时（错误记录、丢失代币、不当行为）转移代币。 ([sec_staff_web_excerpt](https://www.sec.gov/files/tm/no-action/dtc-nal-121125.pdf))
- 转换指令（代币化/去代币化）可在周一至周五美东时间凌晨2点至下午6点提交；已注册钱包之间的代币转移可全天候进行。 ([notice_das001](https://files.dtcc.com/download/assets/DAS-001/8a31d732d2d311f1a30ef632b7f70f6d))

## 候选传导链

以下编号为新增 DAS 研究编号，尚未改动原有 final16 卡片或生产新闻分类器。

### DAS-01 网络/系统韧性——DTS基础设施中断

网络或DTS系统不可用可能延迟转换指令或代币转移，使依赖及时转换或抵押品移动的参与者出现运营延误。系统隔离旨在限制影响扩散；不能直接推定核心DTC系统中断或参与者发生损失。

- 内部缓冲指标：经测试的备用处理能力／峰值所需处理量
- 所需真实数据：备用站吞吐量、峰值转换指令速率，以及 LedgerScan/Factory 灾难恢复测试结果。
- 模拟边界：可做基于假设的敏感性测试。公开网络运行状态不能当成 DTS 私有网络的真实运行记录。

### DAS-02 记录/对账——LedgerScan账本偏差风险

LedgerScan记录与链上状态不一致可能需要对账或受控更正；积压可能延迟权益处理，并影响DTC向SEC工作人员提交的季度报告。这是条件性假设；报告承诺由DTC承担，尚未取得公开实测结果。

- 内部缓冲指标：单位时间内可解决的对账差异／同一时间尺度的峰值待解决积压
- 所需真实数据：对账处理能力、受控撤销或更正调用记录、积压数量与解决时间。
- 模拟边界：可检验流程和参数敏感性；没有真实对账积压数据，不能据此验证实际风险。

### DAS-03 钱包/安全——已注册钱包被攻击或OFAC筛查失效

钱包私钥泄露导致代币在已注册钱包间被未授权转移→LedgerScan检测到转移但撤销需根钱包介入→撤销延迟造成所有权争议窗口→若OFAC筛查失效，DTC及参与者面临制裁风险；已注册钱包限制降低但不能完全消除未授权转移风险。

- 内部缓冲指标：已核实采用多方授权控制的代币化资产／DTS 代币化资产总额
- 所需真实数据：钱包密钥管理证明、对应资产金额、已注册钱包清单及制裁名单复筛记录。
- 模拟边界：可做假设覆盖率敏感性测试；合作机构名单不能直接视为已批准托管商名单。

### DAS-04 资格/监管——SEC不采取行动立场撤销或资格边界违反

适用监管条件改变，可能按官方要求触发服务限制、规则备案或应急转换；转换能力相对于受影响头寸的规模决定假设中的调整负担。不能直接认定会强制转换或发生执法行动。

- 内部缓冲指标：一天内可应急去代币化的头寸／受影响代币化头寸
- 所需真实数据：应急转换处理能力、受影响头寸规模、应急操作手册及资格监控规则。
- 模拟边界：可测试给定监管情景下的转换负担；不能用模拟结果估计监管撤销概率。

### DAS-05 转换/公司行动容量——窗口拥堵与公司行动处理

峰值转换需求超过处理能力可能形成队列并延迟参与者工作流；公司行动支付错误可能需要更正。函件允许两类与DTC核心系统的有限接口：数字总括账户证券转入转出，以及公司行动现金支付，后者并非唯一接口。本次研究未证实已经发生处理失败。

- 内部缓冲指标：每小时转换处理能力／每小时峰值转换需求
- 所需真实数据：转换吞吐量、同一小时尺度的峰值需求、排队规则和公司行动处理错误记录。
- 模拟边界：可测试假设需求下的队列和处理能力；当前没有真实 DTS 指令量或处理上限。

## 验证与模型接口

风险框架保留 S × V，不加 E。先用业务机制确定相关性，再对外部冲击信号做事件检验；取得真实内部指标后，分别做同季度传导检验和下一季度预测检验。

当前缺少连续真实 V：季度可用性表保留空值。若后续制作 2020Q4–2026Q2 的模拟序列，必须全部标成服务上线前的反事实模拟，并与真实值分表；不得称为历史实测或实证验证。

原有16卡的6张PQD V与10张真实公开代理V是不同层级；公开代理不是模拟值。新增DAS尚无已接受的代理V序列。见[与团队流程的衔接](TEAM_PIPELINE_ALIGNMENT_CN_EN.md)。

有合适序列后，沿用现有 V 算法：p = 历史值中小于等于当前值的比例；V = max(1, ceil(5p))。先按风险方向转换，只使用当时可获得的历史，短历史单独标记。
