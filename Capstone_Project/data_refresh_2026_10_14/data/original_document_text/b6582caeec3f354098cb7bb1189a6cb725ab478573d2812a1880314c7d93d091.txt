DRS Withdrawal by Transfer Transaction Processing  
 
On November 12, 2025, through Important Notice B#23200-25, The Depository Trust Company (“DTC”) 
announced the user roles and entitlements for DRS Withdrawal by Transfer on the Securities 
Processing Application (SPA) system.  This change, which includes the automation of centralized billing 
for Transfer Agent pass-through fees on the SPA system, is part of DTC’s multi-year, multi-phase 
Securities Processing Transformation Program. 
 
The transformation of the DRS system, pending regulatory approval, progresses through a phased 
rollout of component functionalities at scheduled intervals. 
 
DRS Profile Deposits, DRS Withdrawal by Transfer and DRS Centralized Billing will transition to the 
SPA system on November 13, 2026.  
 
DRS Centralized Billing 
 
DRS Reject Centralized Billing is being expanded to include centralized billing for DRS Profile Deposits 
and DRS Withdrawal by Transfer transactions and will become a mandatory service on the SPA 
system. 
 
Legacy Withdrawal by Transfer Scope 
 
The following Withdrawal by Transfer activities will continue to be processed on PBS via the FAST SCL 
Confirmation function and the RSATFX transaction file. The CF2DMX file will continue to provide 
transaction status output for Withdrawal by Transfer transactions (see below for full descriptions of 
these files)
. 
 
• Certificated Withdrawals (e.g.; DRS Eligible non-participating certificate only issues) 
• Withdrawals of certain DTC-eligible securities by foreign national investors

How it works 
 
The DRS Eligible Indicator contained in each DTC-eligible CUSIPs master record as set by DTC will be 
used as the gatekeeper for Withdrawal by Transfer transactions to route and process through PBS and 
SPA. 
 
For automated transaction processing firms can find the DRS Eligible Indicator on the ELISC/ELISCD 
Eligible Corporate Securities/Eligible Corporate Securities with Descriptions data file (Position 44, 
Length 1, Format Character, Field Name, Field Description “N” = Non-Eligible for DRS, “Y” = DRS 
Issue).  Firms may use the DRS Eligible Indicator to direct transactions to PBS or SPA as applicable.   
 
All certificated issues (non-DRS Eligible securities) with the DRS Eligible Indicator set to “N” will be 
rejected upfront when entered in SPA via the SPA portal or API/MQ connectivity.  The system will 
return a message indicating “DRS eligible issue not participating” or “CUSIP is not DRS Eligible”.  
These rejects will need to be resubmitted to PBS or CCF file CF2WTC/WTM and will be available to 
FAST Transfer Agents on PBS via the FAST SCL Confirmation or RSATFX file.   
 
All DRS Eligible issues with the DRS Eligible Indicator set to “Y” will be rejected upfront when entered 
in PBS via the Auto Withdrawal by Transfer function and CCF file CF2WTC/WTM.  The system will 
return a message indicating “DRS Issue Should be Entered via SPA Portal” or error code “H”, “Invalid 
or Missing DRS Info” via file.  These rejects will need to be resubmitted to SPA and will be available to 
FAST Transfer Agents on SPA via DRS Withdrawals, Pending Approval or API. 
 
Firms instructing Withdrawal by Transfer of U.S. Securities with Restrictions on Foreign Ownership (for 
foreign national investors) are required to attest to citizenship and should direct these transactions to 
PBS or CF2WTC/WTM file.  These transactions will be available to FAST Transfer Agents on PBS via 
FAST SCL Confirmation function or RSATFX file.   
 
CCF File Descriptions 
 
• FAST Withdrawal by Transfer RSATFX – allows Transfer Agent to receive Withdrawal by 
Transfer transactions and approve or reject through automation. This file will continue to provide 
physical certificated Withdrawal by Transfer transaction instructions (as applicable) for the 
foreseeable future (DRS Withdrawal by Transfer transactions will move to SPA via the DRS 
Withdrawal by Transfer API or MQ).     
 
• Direct Mail Agent Return CF2DMX – allows Transfer Agents to provide status of Withdrawal by 
Transfer transactions.  This file will continue to provide transaction status information for 
physical certificated Withdrawal by Transfer transactions (as applicable) for the foreseeable 
future (DRS Withdrawal by Transfer transactions will move to SPA via the Withdrawal by 
Transfer API or MQ).     
 
 
This change will be effective on November 13, 2026.
