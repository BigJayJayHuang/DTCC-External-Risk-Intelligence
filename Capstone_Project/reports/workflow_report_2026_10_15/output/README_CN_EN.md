## 阅读内容 / Coverage
公开数据采集、共享数据库、数据清洗与时间对齐、九条 FICC 逻辑链、十条业务线的风险传导路径、历史 Ridge 模型训练、事件与 PQD 验证、同一事件的分业务评估，以及 SVB 历史事件示例。

Public-data collection, shared storage, cleaning and time alignment, nine FICC logic chains, pathways for ten business lines, historical Ridge training, event and PQD validation, business-specific assessment of a common event, and a historical SVB example.

## 数据与结论边界 / Evidence boundaries
报告复核了现有项目文件，没有为写报告重新训练模型。历史模型与 PQD 检验的冻结观测截至 2026Q2；共享数据库及公开数据更新使用 2026-10-14 已核实的项目状态，不代表每个来源都有截至编制日的观测。

The reports verify existing project artifacts without retraining models. Frozen model/PQD observations end in 2026Q2; database and collection status reflects the verified project state on 2026-10-14. Preparation date does not mean every source has observations through that date.

流程图蓝色代表已有数据或研究环节；灰色虚线代表仍待整合或验证的模块。完成检验不等于传导关系或风险分数已验证。报告中的 S×E×V 数字算例完全是假设值，不能作为实际 DTCC 风险分数或损失概率。

Blue diagram boxes denote existing data or research steps. Dashed gray boxes denote proposed or unvalidated modules. Tests having been run does not establish transmission or valid risk scores. Numerical S×E×V examples are hypothetical teaching inputs, not actual DTCC risk scores or loss probabilities.

Each Word report includes its language-matched flowchart. Standalone PNG/SVG files can be inserted into presentations. Both reports contain an evidence index and official reference links.
